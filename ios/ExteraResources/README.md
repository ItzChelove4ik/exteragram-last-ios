# ExteraResources

Первый отдельный модуль ресурсов для будущего порта присланной exteraGram Lite. Это Swift Package с локализациями и английским fallback. Здесь ещё нет клиента Telegram, экранов настроек или реализации функций мода.

Исходный APK: `exteraGram-lite-universal-20261004.apk`, версия манифеста 12.10.6. Точная привязка ресурсов, количество строк и результаты проверки сохранены в `provenance.json`.

Генерация: `python ../../analysis/port_localizations.py` из папки этого пакета. Преобразуются Android escape-последовательности и `%s` → `%@`. Форматные аргументы переводов сверяются с английскими; несовместимый перевод исключается, чтобы использовался английский fallback. Исходные тексты всех языков сохранены в `analysis/localizations.json`.

Добавить локальный пакет в будущий проект iOS и вызвать:

```swift
import ExteraResources
let title = ExteraLocalization.text("Preferences")
let russianTitle = ExteraLocalization.text("Preferences", languageCode: "ru")
```

Разметка (`**...**` и другие формы) остаётся в строках и требует соответствующего рендеринга интерфейсом. Для форматирования `%d` нужно передавать совместимый 32-битный целочисленный аргумент; `%@` принимает объект или NSString.

Проверка сериализации и обратного чтения каждой строки выполняется генератором. XCTest-проверки покрывают русский и английский lookup, английский fallback, отсутствующие ключи и преобразование escape/format строк. В текущей Windows-среде нет Swift/Xcode/macOS; результат компиляции и тестов следует подтвердить GitHub macOS CI. Минимум iOS 15 в Package.swift относится только к этому модулю ресурсов; системные требования будущего приложения ещё не определены. `Bundle.module` создаётся SwiftPM; при интеграции напрямую через Bazel потребуется явный accessor для bundle.
